## Findings that are new on this phone

1. **`adb install` also installs into the Dual App space.** Settings showed two "Spikes" apps; the copy in the Dual App profile (user 95) had no permissions. Use `adb install --user 0` for pilot installs, or remove the copy with `pm uninstall --user 95`. This would confuse a user following setup steps.
2. **The test app logged the SMS sender address unredacted**, which for a person-to-person message is a phone number. The real app must keep sender IDs only for allowlisted bank sender names and drop everything else (CAP 02, RAW 01).
3. **The name heuristic is limited.** A first name in free text is not caught by the redactor (it only catches names after "Dear" or a title). Keep the sanitised excerpt rule strict in the real app.

## Result

The Z Flip 5 behaves like the S25 Ultra: SMS receipt, listener access and posting are independent, SMS survives swiping away and the Restricted setting, and does not survive a force-stop until the user opens the app.
