## Observations

| Check | Result |
|---|---|
| All 8 instrumented tests | 8 of 8 pass |
| Wrapping key security level | **trusted environment** |
| Export then restore on a clean install | Same rows back, PBKDF2 and Argon2id |
| PBKDF2-HMAC-SHA256, 600,000 rounds | export 4.2 s, restore 3.4 s |
| Argon2id, 19 MiB, 2 passes, 1 lane | export 1.4 s, restore 0.4 s |
| Test apps after the run | Removed (checked for the main user) |

## Result

Behaviour is the same as on the S25 Ultra. The Z Flip 5 is the slower phone: PBKDF2 at 600,000 rounds takes 4.2 s to export, against 1.4 s for Argon2id. Both are acceptable for a rare, user-triggered export, but PBKDF2 is about three times slower on both phones, which favours Argon2id.

## Limits and decisions

1. A real force-stop and reboot restart against stored data is not yet exercised.
2. The PBKDF2 or Argon2id choice is the user's decision. Evidence now covers the emulator and both pilot phones.
